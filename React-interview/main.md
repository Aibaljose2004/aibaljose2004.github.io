## 🛠️ How to Use This Guide

1. **Read the Scenario First:** Treat each prompt like a real ticket in a timed coding interview.
2. **Build Before Peeking:** Attempt to write the code in your local environment or sandbox before checking the solution.
3. **Review the Explanation:** Compare your implementation with the provided code examples to learn cleaner patterns and edge-case handling.
